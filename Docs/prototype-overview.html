ポータルで、事故のタイミングをずらす

ヴィランが交通を混乱させた街。ヒーローが制圧するまでの 60 秒間、事故が起きそうな車を次元ポータルで別次元へ飛ばし、数秒後に同じ場所へ戻して衝突を避ける。

イメージ合わせ用にブラウザで作った簡易版で、Unity の実装ではありません。内部解像度を 480×270（960×540 に対して 2 倍）にし、交差点を中央寄りに置いて、車が見えてから最初の交差点まで 2.3〜4 秒かかるようにしています。下のスイッチで「ポータルが開くまでの時間」と「予告の秒数」を切り替えて比べられます（切り替えると最初からやり直し）。その他の数値は Docs の初期値（車 3 マス/秒、ポータル最大 3 個、別次元 2 秒、出現間隔 1.2→0.5 秒）です。

コアループ

ポータルに入った車に起きること

  1. 1予告が出る

    このまま進むと 2 秒以内にぶつかる組に「！」が出て、車が点滅する。

  2. 2道路にポータルを置く

    クリックで設置。同時に置けるのは 3 個まで。

  3. 3車が別次元へ

    ポータルに入った車は消え、当たり判定もなくなる。ポータルは 1 台で消える。

  4. 42 秒後に同じ位置へ

    同じ経路・同じ速度で走り出す。交差点に着くタイミングだけがずれる。

戻った位置に後ろの車が来ていれば、そのまま事故になります。交差点が 4 つあるので、ずらした車が次の交差点でぶつかることもあります。「どの車を、どこで飛ばすか」を読むのがこのゲームの判断です。

「予告を見てクリックするだけ」にしないため、判断を生む軸を 2 つ持ちます。A：反応だけでは間に合わない状況を作る（予告の数がポータルの数を上回る、ポータルが開くまでに時間がかかる、予告を短くする）。B：解決した結果が次の問題を生む（上の連鎖）。序盤は予告を見て置くだけで解け、中盤以降は反応だけでは足りなくなる形を目指します。

Docs/features/

プロトタイプの機能

01

道路と経路

  • 1 画面のマップ、カメラ固定。見た目は Tilemap
  • 車のルートは手で置いたウェイポイント。「距離 → 位置と向き」を返す
  • 内部解像度 480×270。縦 2 本 × 横 2 本の道路で交差点 4 つ・直進のみ。忙しさは交差点の数で出す
  • 交差点は中央寄りに置き、車が見えてから最初の交差点まで 3〜4 秒以上を目安にする
01-road-and-routes.md
02

車の出現と移動

  • 出現点から一定速度（3 マス/秒）で進み、消滅点で消える。止まらない・追い越さない
  • 出現間隔（マップ全体）は 1.2 秒 → 0.5 秒に縮む
  • 物理演算ではなく「経路上の距離」で動かす（未来の位置を計算しやすい）
02-car-spawn-and-move.md
03

衝突判定と事故予告

  • 走っている車どうしが重なったら事故（Collider2D トリガー）
  • 未来の位置を 0.1 秒刻みで計算し、2 秒以内にぶつかる組に「！」と点滅
  • 予告の秒数は調整対象（2 秒前 / 1.2 秒前を比べる）
03-collision-and-warning.md
04

ポータル

  • 道路上をクリックで設置、同時に最大 3 個
  • 入った車は別次元へ。2 秒後に同じ位置へ戻る。戻る位置に残り時間を表示
  • 1 台飛ばすと消える。置いてから開くまでの時間を調整できる（初期値 0 秒）
04-portal.md
05

ゲーム進行

  • シーンを開くと開始。残り 60 秒を表示
  • 0 秒でクリア、事故でゲームオーバー（事故地点を強調してから結果）
  • クリックかキーでリトライ。タイトル画面は α 版で追加

あとから足す難しさ

  • 車の種類：速い車、遅いバス、長いトラック。同じ経路でも追突が起きる
  • ヴィランのイベント：信号故障で一斉に車が来る、逆走車、道路封鎖など。途中でルールが変わる
  • 飛ばせない車：救急車など。ほかの車を飛ばして道を空ける
  • 後半は予告が短くなる（2 秒前 → 1.2 秒前など）
