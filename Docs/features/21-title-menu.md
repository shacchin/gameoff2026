# タイトルのメニュー

## 目的

タイトルで「どこかを押すとすぐ始まる」のをやめ、START / HELP / CREDITS を選べるようにする。初めての人が遊び方を確かめられ、素材やフォントのライセンス表記を載せる場所も作る。

## 仕様

- タイトル文字の下に、縦に 3 つの項目を並べる: `START` / `HELP` / `CREDITS`
  - 背景の車（20）はそのまま流し続ける
- マウスだけで選ぶ（キー操作は付けない）
  - 項目にカーソルを乗せている間だけ選択中になり、クリックで決定。外れると何も選んでいない状態に戻る
  - 最初は何も選んでいない状態
  - 選択中の項目は、頭に `>` を付けて色を変える
- START: 今までどおり決定音を鳴らして `Game` シーンを読み込む
- HELP / CREDITS: 同じシーンの上にパネルを重ねて出す（別シーンにはしない）
  - パネルの `BACK`、右クリック、Esc でメニューに戻る
  - パネルを出している間は、タイトルの文字とメニューを隠す（背景の車は走らせたまま）。`TitleScreen` の Hide While Panel Open に入れたものを隠す
- HELP の中身: 見出し `HOW TO PLAY` の下に、遊び方のカードを左から右へ 3 枚並べる。各カードは上に動くデモ、下に英語の説明 1〜2 行
  1. PORTAL: クリックでポータルを置く。入った車は消えて、少しあとに同じ位置へ戻る
  2. CRASH: タイミングをずらして車をぶつける。続けて起こすとコンボ
  3. POLICE: 警察車両は事故で壊す。3 台見逃すとゲームオーバー
  - 配置（Canvas の基準 960×540）: カードは 280×320 を 24px あけて横に並べる（中心 X = -304 / 0 / 304、Y = -10）。カードの中は上から、見出し（Press Start 2P・黄色）、デモ（256×150）、説明（Pixelify Sans・256×100）
- デモは本物のゲームを動かさず、車・ポータルの絵を UI の Image として並べて DOTween で動かす人形劇にする（`HelpDemo`）。くり返し再生し、パネルを開くたびに最初から始める
  - PORTAL・CRASH 共通: 最初にカーソルを出し、0.6 秒たってからクリックしてポータルを開く（カーソルが一瞬しか見えないと、クリックで置くことが伝わらないため）。車はポータルが開いてから着くように、必要なら出発を遅らせる
  - PORTAL: 右へ走る車の前にカーソルがポータルを置く → 車が回りながら吸い込まれ、戻る位置の目印が残る → 同じ位置に戻って走り去る
  - CRASH: 上へ走る車をポータルで遅らせ、交差点で右へ走る車とぶつける → 2 台が消えて事故の絵と `+100` が出る
  - POLICE: 警察車両が走り抜けるたびに `MISS 1/3` → `2/3` → `3/3` と増え、3 台目で `GAME OVER`
  - デモでは音を鳴らさない（パネルを見ている間ずっと鳴ると、うるさいため）
  - ポータル・目印・事故の絵は、`HelpDemo` がコマを切り替えてアニメーションさせる（10 コマ/秒。portalIn / portalOut の 1 コマ 100ms に合わせた）
    - 理由: Aseprite の読み込みで作られる Animator は SpriteRenderer の絵を書き換えるもので、UI の Image には効かないため
- CREDITS の中身: 作者と、使った素材の配布元・ライセンス・URL
  - 見出し `CREDITS` の下に作者を 1 行（`Game by shacchin`）
  - その下に本文を左右 2 列で並べる。各項目は「黄色の見出し／名前とライセンス／小さい灰色の URL」の 3 行
  - 左: VEHICLES（Pixel Vehicles by MinZinn、CC BY 4.0）、TILES / CITY（TopDown City by El Beshuele）
  - 右: MUSIC / SOUND（OtoLogic、CC BY 4.0 ／ Sound Effect Lab）、FONTS（Press Start 2P / Pixelify Sans、SIL OFL 1.1）
  - URL は文字で見せるだけで、押しても開かない（`https://` は省く）
- パネルは全面を黒の半透明（75% くらい）で覆い、後ろで車が走るタイトルを暗く見せる。全面の Image が後ろのメニューへのクリックも止める
- 文字は英語（19）。メニュー・見出し・BACK は Press Start 2P、HELP と CREDITS の文章は Pixelify Sans
- タイトルを出してから 0.3 秒は入力を受け付けない（今の `inputDelay` を引き継ぐ）

## 決定事項

- HELP は文字に絵を添える。ページ送りはしない（11/25、ユーザーの判断）
- HELP の絵は動くデモにし、横 3 枚のカードで並べる（11/28、ユーザーの判断）。最初の「縦 3 段・左に止まった絵」から変えた
  - 理由: デモを主役にするなら、横に並べたほうが 16:9 の画面で大きく見せられる
  - デモは人形劇（UI の Image を DOTween で動かす）にした。録画をコマ送りにする案・VideoPlayer で動画を流す案は、手間やビルドの重さ、WebGL での再生の不安があり、提出前日には向かないためやめた
- クレジットは名前・ライセンスに加えて URL も小さく出す（11/28、ユーザーの判断）。11/25 の「URL は画面に出さない」から変えた
  - URL をクリックで開くのはやめた。WebGL の `Application.OpenURL` はブラウザのポップアップブロックに止められることがあり、確実に開くには jslib がいる。押せるリンクは itch.io のページに置く
- クレジットの本文は 1 列では窮屈だったので左右 2 列にする（11/28、ユーザーの判断）
- 効果音ラボは英語名の `Sound Effect Lab` で書く（11/28）
  - 理由: Pixelify Sans の Font Asset は ASCII だけなので、日本語が表示されない（19）
- 作者は素材と分けて、見出しのすぐ下に 1 行で出す（11/28、ユーザーの判断）
- パネルの BACK も、メニューと同じくカーソルを乗せている間だけ選択中にする（11/28、ユーザーの判断）。最初はいつも選択中に見せていた
  - 理由: メニューは乗せるまで灰色なのに、BACK だけ最初から黄色だとちぐはぐに見えるため
- メニューの項目は `Button` ではなく、文字に付けた `TitleMenuItem` がカーソルとクリックを受ける（11/25）
  - 理由: `Button` はクリックした項目が EventSystem の「選択中」として残り、カーソルを外しても色が戻らない。`>` を付ける見た目も自前の方が簡単
- HELP と CREDITS の文章は Pixelify Sans にする（11/25、ユーザーの判断）
  - 理由: Press Start 2P は横に広く、数行の文章だと読みにくい。19 で「説明文に使うかもしれない」と残しておいたもの
- 選択中はカーソルを乗せている間だけにする。最初に START を選んでおく案はやめた（11/25、ユーザーの判断）
  - 理由: 何もカーソルを乗せていないのに選択中の項目があると違和感があるため
- メニューはマウスだけで操作する（11/25、ユーザーの判断）。最初は ↑↓ / Enter でも選べるようにしていたが外した
  - 理由: ゲーム本体の操作がマウスだけなので、タイトルだけキーで動かせても使われない
  - パネルを閉じる Esc だけは残す。Web のモーダルと同じ感覚で押されそうなため

## 実装メモ

- 変更: `TitleScreen` がメニューの選択とパネルの開閉を受け持つ。各項目の文字に付けた `TitleMenuItem` が、カーソルの出入りとクリックを `TitleScreen` に伝え、選択中の見た目（`>` と色）を切り替える
- 設計判断: 項目の用意は `Awake` ではなく `TitleMenuItem.Init` で行う。`TitleScreen.Awake` から先に呼ばれることがあり、非表示のパネル内の BACK は `Awake` がまだ走っていないため
- 設計判断: 中央揃えで左に `> ` を付けると文字が右に寄るので、右にも同じ幅の透明な文字（`<color=#00000000>`）を付けてつり合いを取る。行末を空白にすると幅に数えられないことがあるので、右は ` >` にしている
- 注意点: 選択の印は等幅フォント（Press Start 2P）が前提。メニューの文字を Pixelify Sans にすると、選択のたびに文字が動く。TMP の Rich Text もオンのままにする
- 注意点: Help Panel / Credits Panel が空のとき、HELP / CREDITS を押しても何も起きない（エラーにもならない）。パネルには全面の Image を敷き、後ろのメニューにカーソルが届かないようにする
- 変更: HELP のデモは `HelpDemo` が枠の子に地面・道路・車などの Image を `Awake` で作り、`Play` で 1 回分の Sequence を作っては `OnComplete` で作り直してくり返す。シーンには枠と絵の割り当てだけを置く
- 設計判断: `SetLoops` ではなく毎回作り直す。位置・大きさ・表示を毎回置き直せるので、途中で消した車や、色を変えた MISS の文字を戻す処理がいらない
- 設計判断: CRASH の右へ走る車は、上へ走る車がぶつかる時刻から逆算して出発させる。速さ・枠の大きさ・`Cursor Lead` を変えても交差点で同時に着く
- 注意点: ポータル・目印・事故の絵はコマの配列で受け取り、`Update` で差し替える。Aseprite が作る Animator は UI の Image に効かない。`cursor.aseprite` は中心を合わせる枠の絵なので、pivot は中央のままにする
- 動作確認: エディタで Title を Play し、メニューの選択と START をユーザーが確認した（11/25）。続けて CREDITS と HELP のパネル、3 つのデモ（ポータルのアニメーション、先に出るカーソル）が動くことをユーザーが確認した（11/28）。WebGL ビルドは未確認
