# ポータル

## 目的

このゲームの中心の操作。車を一時的に別次元へ「シフト」させて、交差点に着くタイミングをずらし、事故を防ぐ。

## 仕様

- 道路の上をクリックするとポータルを置ける（道路以外には置けない）
- 同時に置けるのは最大 3 個（`[SerializeField]`）。上限に達しているときは置けない
- ポータルに入った車は別次元へ消え、一定時間後（初期値 2 秒）に**同じ位置**へ戻り、同じ経路・同じ速度で走り出す
- 戻った位置に別の車がいれば、そのまま事故になる（ずらしすぎると後続の車とぶつかる、というリスク）
- ポータルは車を 1 台飛ばすと消える（消えたら、また置けるようになる）
- 置いてから開くまでに時間がかかる（初期値 0 秒、`[SerializeField]`）。開くまでは車を吸い込まない
- 車が戻ってくる位置には、戻るまでの残り時間を表示する

## 決定事項

- 配置方法は、プロトタイプではクリック配置にする
  - 理由: 一番早く試せるため。自キャラが移動して置く方式、射程付きで置く方式は、触ってから比べる
- 戻る位置は「飛ばした位置と同じ」。距離ワープのポータルは追加レベルの候補にする
  - 理由: 事故はタイミングの問題なので、時間をずらすのが自然な解決になる。テーマ SHIFT（時間のシフト）にも合う
- 「予告を見てクリックするだけ」にしないため、判断を生む軸を 2 つ持つ（11/2）
  - A. 反応だけでは間に合わない状況を作る: 後半は予告の数がポータルの数を上回る／ポータルが開くまでに時間がかかる／予告を短くする
  - B. 解決した結果が次の問題を生む: ずらした車が後ろの車や次の交差点の車とぶつかる
  - 目指す形: 序盤は予告を見て置くだけで解ける（チュートリアル）が、中盤以降は反応だけでは足りなくなる
