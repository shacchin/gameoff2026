# 警察車両とゲームオーバー（時間無制限のスコアアタック）

## 目的

60 秒の制限時間をなくし、「どこまでスコアを伸ばせるか」を競うゲームにする。終わりの条件として、ときどき来る警察車両を事故で破壊できずに見逃すとゲームオーバーにする。

## 仕様

- 制限時間はなくす。ゲームが終わるのは、警察車両を 3 台見逃したときだけ
- 警察車両
  - 一定の間隔で、横の道路の「左から右へ進む車線」（2 本）のどちらかにランダムに出す
  - 速度はほかの車と同じ。見た目は `TopDownVehicles/POLICE_CLEAN_ALLD0000-sheet.png`
  - ほかの車と事故を起こしたら「破壊」。点数は普通の事故と同じ（1 件 100 点）
  - ポータルで飛ばせる（ほかの車をずらしてぶつけても、警察車両をずらしてもよい）
  - **自動では事故を起こさない**: 警察車両はほかのどの車ともぶつからないタイミングでだけ出す。つなぎの車・予約した事故の車も、警察車両とぶつからない場合だけ出す。予約する事故の 2 台に警察車両は使わない
    - プレイヤーがポータルでずらした結果の事故は防がない
  - 右端まで走り切ったら「見逃し」1 回
  - 出現の予告は出さない
- 出現の頻度
  - 各幕（`GameTuning` のセクション）に、出現の間隔（最小〜最大秒。その範囲からランダム）を持たせる
  - ゲーム開始から最初の 1 台までの秒数は `GameTuning` に 1 つだけ持たせる
- 第 3 幕のあと（60 秒以降）は、第 3 幕を繰り返す（つなぎの車・事故の予約・山場・谷・警察車両の頻度すべて）
- 画面の表示
  - 残り時間の代わりに、見逃した数を出す（`MISS 1/3`）
  - 3 台目を見逃したらその場でゲームオーバー → 結果画面に「GAME OVER」と最終スコア（RETRY / TITLE は今のまま）
- スコアのシステム（事故 1 件 100 点）は変えない

### 今回やらないこと

- 出現の予告（矢印・点滅など）
- 警察車両のボーナス点
- 結果画面に生き残った時間を出す

## 決定事項

- 上の仕様はすべてユーザーと確認して決めた（11/22）
- 最初の 1 台までの秒数は幕ごとではなく 1 つだけにした（11/22）
  - 理由: 幕が変わるたびに「最初の 1 台」を決め直すと、幕の境目で間隔が急に詰まったり空いたりする。間隔だけ幕ごとに変えれば頻度の調整には足りる
- 見逃した数の表示は、今まで残り時間を出していたテキストをそのまま使う（`GameUI` の `timerText` を `missText` に改名し、`FormerlySerializedAs` で設定を引き継ぐ）
- `TIME UP!` の文言は `GAME OVER` に変えた。`GameManager.State.Finished` は `GameOver` に改名した

## 実装メモ

- 変更: `CarSpawner.UpdatePolice` が警察車両を出し、`Car.PoliceEscaped` を `GameManager` が数えてゲームオーバーにする。`WaveDirector.SectionAt` が最後の幕を繰り返す時刻の計算を受け持ち、`CarSpawner` の谷・事故の予約もここを使う
- 設計判断: 警察車両は `Car` に `isPolice` を足しただけの別 Prefab にした。ポータル・事故の判定・ぶつからないかの確認がそのまま効く
- 設計判断: 警察車両が自動で事故を起こさないのは、`IsSafe` で「出す前に、出したあとも含めてぶつからないか」を調べる仕組みに乗せているため。新しい出し方を足すときも `IsSafe` を通すこと
- 設計判断: `WaveDirector` の `logSection` で、幕が始まるたびに Console に出す（繰り返し中は「（繰り返し）」と付く）
- 注意点: TopDownVehicles は `.gitignore` に入っているので、警察車両のシートの設定（PPU 100・100×100 で切り出し・ピボットは中央）は git に残らない。別の環境では設定し直す
- 注意点: `GameTuning.asset` は、インスペクターで値を触るまで新しい項目が書き出されない。今回は値を直接書き込んだ
- 動作確認: エディタで Play し、警察車両が出る・見逃しが数えられる・破壊で点が入る・3 台でゲームオーバーになることをユーザーが確認した（11/22）。幕のログは未確認。WebGL ビルドも未確認
