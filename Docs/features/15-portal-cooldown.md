# ポータルのクールダウンとゲージ

## 目的

ポータルを連打して事故を量産できないようにする。次にいつ置けるかが分かるように、待ち時間をカーソルの下にゲージで出す。

## 仕様

- （試し）同時に置けるポータルは 1 個（シーンの `PortalPlacer` の `Max Portals` を 1 にする）
- ポータルが車を飲み込んだ瞬間から、`cooldown`（試しで 1 秒。車が別次元にいる時間 `shiftDuration` と同じなので、車が戻った瞬間に置ける）の間は次のポータルを置けない
  - 車を飲み込まずに時間切れで消えたときは、クールダウンなしですぐ置き直せる
- クールダウン中は、カーソルを「置けない」絵にする（数の上限で置けないときと同じ絵）
- クールダウン中だけ、カーソルのすぐ下にゲージを出す。左から右へ溜まり、溜まりきったら消える

## 決定事項

- クールダウンは「ポータルが消えてから」ではなく「車を飲み込んでから」数える（11/22）
  - 理由: 置き損ねて時間切れになったときまで待たせると、テンポが悪くなるため
  - `Portal.CarShifted` のイベントで始める
- ゲージは画面の隅（HUD）ではなく、カーソルの下に出す（11/22）
  - 理由: プレイ中はカーソルの近くを見ているので、目を離さなくても分かる
- ゲージは `PortalPlacer` が実行時に作る（白い四角の Sprite に色を付ける）。絵や Prefab を用意しなくてよく、大きさ・色はインスペクターで変えられる

## 実装メモ

- 変更: `PortalPlacer` に `cooldown` と `cooldownEndTime` を足し、`Portal.CarShifted` を購読して始める。ゲージは `CreateGauge` がカーソルの子に作り、`UpdateGauge` で出し入れと溜まり具合を更新する
- 設計判断: ゲージの溜まる部分は左端をピボットにした Sprite を作り、横の Scale だけ変える（位置の計算がいらない）
- 設計判断: ゲージをカーソルの子にしたので、ゲーム終了でカーソルが消えると一緒に消える
- 注意点: `Sprite.Create` の pixelsPerUnit をテクスチャの幅にして 1 マス = 1 ユニットにしている。Grid の Cell Size やカーソルの Scale を 1 以外にすると、ゲージの大きさがずれる
- 注意点: `Max Portals` はシーンに保存された値が使われる。コードの初期値を変えても反映されない
- 動作確認: ゲージの出方をユーザーが確認した（11/22）。WebGL ビルドは未確認
