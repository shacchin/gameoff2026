# 事故でスコアを稼ぐ（ルール転換）

## 目的

コアルールを「事故を防ぐ」から「事故を起こしてスコアを稼ぐ」に変える。ポータルで車のタイミングをずらし、狙って事故を起こす遊びにする。

## 仕様

- 事故が起きてもゲームは止めない。60 秒たったら終わり、リザルトへ進む（ゲームオーバーはなくなる）
- 事故 1 件ごとにスコアを固定点（初期値 100、`[SerializeField]`）加える
  - プレイ中は画面に今のスコアを出し続ける
- 事故の瞬間のフィードバック
  - 事故の地点に事故マークを出す（今のゲームオーバー時のマークを流用）。少しのあいだ見せてから消す
  - 事故の地点に「+100」のポップアップを出す（上に浮かびながら消える）
- 事故に関わった車は、事故の瞬間にすぐシーンから消す（交通の流れを止めない）
  - 玉突き・連鎖・事故車を残す仕様は入れない
- 事故予告（「！」マークと車の点滅）は出さない（コードは残し、設定でオフにする）
- リザルトは「時間終了による結果」として、最終スコアを出す
  - ボタンは常に RETRY と TITLE の両方を出す（キーも R ＝ リトライ、T ＝ タイトルへ）

### 今回やらないこと

- タンクローリー・爆発
- 玉突き・コンボなどのボーナス（スコアは事故 1 件 ＝ 固定点のみ）
- 交通の出現パターンの調整（今のまま。自然に起きる事故もスコアに入れる）
- ポータルの仕様変更（最大 3 個・2 秒で帰還・1 台で消費はそのまま）
- ゲーム名・タイトル画面の変更

### 進め方

1. ルールの転換: 事故で止めない／事故車を消す／スコアを数えて表示／60 秒でリザルト（最終スコア）
2. 事故のフィードバック: 事故マークを一定時間で消す／「+100」のポップアップ
3. ドキュメント: 05 と CLAUDE.md の企画欄を新ルールに書き換え、実装メモを書く
