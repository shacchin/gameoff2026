# 衝突判定と事故予告

## 目的

車どうしがぶつかったら事故としてゲームオーバーにする。事故 1 回でアウトなので、理不尽にならないよう、ぶつかる前に予告を出す。

## 仕様

- 走っている車どうしが重なったら事故。ゲーム進行（05）に事故の位置を伝える
- 別次元にいる車は、どの車ともぶつからない
- 事故予告: 今の速度のまま進んだとき、一定時間以内（初期値 2 秒）にぶつかる車の組を見つけて、次を表示する
  - ぶつかる予定の地点に「！」マーク
  - ぶつかる予定の車を点滅させる
- 予告までの時間は `[SerializeField]` で調整できる

## 決定事項

- 衝突は Collider2D のトリガーで判定する
- 予告は、各車の未来の位置を経路から一定間隔（例: 0.1 秒刻み）で計算し、近づきすぎる組を探して求める
  - 理由: 経路と速度が決まっているので、計算だけで正確に予測できる。車は多くても十数台なので、総当たりで足りる
