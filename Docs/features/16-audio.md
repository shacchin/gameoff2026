# BGM・効果音

## 目的

操作の手応え（ポータル・事故）と、気づいてほしい出来事（警察車両が来た・見逃した）を音で伝える。

## 仕様

- BGM: タイトルとゲーム中の 2 曲。ループ再生する
  - リトライではゲームの曲を頭から流し直す（ゲームオーバーで止めているため）
  - ゲームオーバーになったら BGM をフェードアウトして止める
- SE

  | 場面 | 鳴らす場所 |
  | --- | --- |
  | 車がぶつかった | `GameManager.OnAccident` |
  | 警察車両が出てきた | `CarSpawner.UpdatePolice` |
  | 警察車両を見逃した | `GameManager.OnPoliceEscaped` |
  | タイトル・結果画面での決定 | `TitleScreen` / `GameManager.Retry` / `GameManager.GoToTitle` |
  | ポータルを置いた | `PortalPlacer` |
  | ポータルが車を飲み込んだ | `ShiftFeedback` |
  | 車が別次元から戻ってきた | `ReturnMark`（飲み込みの音の逆再生） |
  | 結果画面で項目を 1 つ出した | `GameUI`（17） |
  | 結果画面でスコアを出した・演出を飛ばした | `GameUI`（17） |

## 決定事項

- 音はすべて `AudioManager`（Prefab にして両シーンの `Systems` の子に置く）で鳴らす。鳴らす側は `AudioManager.PlaySe(...)` を呼ぶだけ（11/23）
  - 理由: 決定音を鳴らした直後にシーンを切り替えるので、シーンをまたいで残る（`DontDestroyOnLoad`）オブジェクトで鳴らす必要がある。音の設定も 1 か所で済む
  - 両シーンに置くのは、Game シーンから直接再生しても音が鳴るようにするため。先にあった 1 つだけ残り、あとから来た分は消える
- 逆再生は、実行時ではなく、あらかじめ逆にした WAV を作って使う（11/23）
  - 理由: WebGL ではピッチをマイナスにした逆再生ができない
  - Project ウィンドウでクリップを右クリック →「逆再生の WAV を作る」で、同じフォルダに `元の名前_Reverse.wav` ができる（前後の無音は削る）
- 戻りの音は、鳴り終わる瞬間に車が戻るよう、音の長さのぶん早めに鳴らす（11/23）
  - 理由: 逆再生の音は最後に盛り上がるので、車が出てくる瞬間に合わせたい。合わなければ `Release Ends On Return` をオフにすると、戻った瞬間に鳴る
  - `Release Delay`（秒）で鳴らし始めを遅らせられる（11/23）。別次元にいる時間が短いと、早めに鳴らした戻りの音が飲み込みの音と重なって聞き分けられないため
- 連続で鳴る音（事故・飲み込み・ポータル設置）は、鳴らすたびにピッチを少しばらつかせる
- 音ごとに `Max Duration`（秒）で途中で止められる。止めるときは `Fade Out` の秒数でフェードアウトする（11/23）
  - 理由: 警察車両のサイレンが長すぎるため。音のファイルを編集せずに、インスペクターで長さを調整できるようにした
