# 車の出現と移動

## 目的

交差点に向かって車を流し続ける。時間が経つほど車を増やして、60 秒の中で難しさを上げていく。

## 仕様

- 車は各経路の出現点から一定の間隔で出現し、経路に沿って一定の速度で進み、消滅点で消える
- 車は止まらない・追い越さない（信号や渋滞はない）。同じ経路の車は同じ速度
- 出現の間隔（マップ全体で 1 台出る間隔）は、ゲーム開始時は長く、時間が経つほど短くなる（例: 開始 1.2 秒 → 60 秒時点で 0.5 秒）
- 出現する経路はランダムに選ぶ
- 速度・出現間隔は `[SerializeField]` で調整できる（初期値の目安: 3 マス/秒）
- 車は「いま走っている」「別次元にいる（非表示・当たり判定なし）」の 2 つの状態を持つ（04 ポータルで使う）

## 決定事項

- 車は物理演算（Rigidbody の速度）では動かさず、経路上の距離を毎フレーム進めて位置を決める
  - 理由: 未来の位置を正確に計算できるので、事故予告がシンプルになる
