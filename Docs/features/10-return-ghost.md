# 戻ってくる車のゴースト

## 目的

ポータルで飛ばした車が「いつ・どこへ戻るか」を、残り秒数の数字ではなく、走ってくる半透明の車で直感的に見せる。
後続の車との位置関係も見えるので、戻ったときにぶつかりそうかを読めるようにする。

## 仕様

- 車を飛ばした瞬間から、その車の半透明の写し（ゴースト）を経路の手前から同じ速度で走らせる
  - 位置は「戻る位置 − 速度 × 残り秒数」。残り 0 秒でちょうど戻る位置に重なり、本物と入れ替わる
  - 経路の先頭より手前（画面の外）にいる間は見せない
- ゴーストは見た目だけ。ほかの車と重なっても事故にしない（事故になるのは今までどおり、本物が戻ったあと）
- 戻る位置の目印（ReturnMark）はアイコンだけ残し、残り秒数の文字は出さない

## 決定事項

- ゴーストは飛ばした瞬間から見せる（11/15）
  - 理由: 戻るタイミングが一番正確に伝わる。「時間をずらされた車がいま本来いるはずの場所」なので、テーマ SHIFT とも合う
- 残り秒数の文字は消し、アイコンは残す（11/15）
  - 理由: 残り時間はゴーストが近づくことでわかる。戻る位置は枠として示しておく
  - 文字は `ReturnMark.showTimeText` で戻せる（Prefab はそのまま）
- ゴーストの描画順は -1（本物の車より奥、ポータルより手前）。本物の車を読みやすくするため
- 車の絵を写す処理は `Car.CreateVisualCopy` にまとめ、吸い込み演出（08）と共用する

## 実装メモ

- 変更: `ReturnMark` がゴースト（`ReturnGhost`）を作り、毎フレーム経路上に置き直す。車の絵の写しは `Car.CreateVisualCopy` が作り、`ShiftFeedback` の吸い込み演出も同じものを使う
- 設計判断: ゴーストは ReturnMark の子にせず、同じ親（PortalPlacer）の下に置く。ReturnMark のルートは車の向きに回転しているため。消すのは `ReturnMark.OnDestroy`
- 設計判断: 位置は ReturnMark の残り秒数から毎フレーム計算する（Tween で動かさない）。本物が戻る瞬間と必ず一致させるため
- 注意点: ゴーストは車の `Speed` が一定である前提で位置を出す。別次元にいる間に速度が変わる処理を足すと、ゴーストと戻る時刻がずれる
- 注意点: 秒数の文字は `showTimeText` で `TimeText` ごと非表示にしている。Prefab の `TimeText` は消していない
- 動作確認: エディタで Play し、ゴーストが走ってきて本物と入れ替わる見た目をユーザーが確認した（11/15）。WebGL ビルドは未確認
